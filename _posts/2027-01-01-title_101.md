## The Gamma Integral Identity

When working with Residence Time Distributions (RTD), the raw moments are calculated using integrals of the form $\int_0^\infty t^n e^{-at} dt$. To completely avoid tedious integration by parts, we use the standard Gamma function identity for any integer $n \geq 0$ and constant $a > 0$:

$$\int_0^\infty t^n e^{-at} dt = \frac{n!}{a^{n+1}}$$

### Specific Cases for Exponents $n = 0, 1, 2$:
* **For $n = 0$:**  
  $$\int_0^\infty e^{-at} dt = \frac{0!}{a^1} = \frac{1}{a}$$
* **For $n = 1$:**  
  $$\int_0^\infty t e^{-at} dt = \frac{1!}{a^2} = \frac{1}{a^2}$$
* **For $n = 2$:**  
  $$\int_0^\infty t^2 e^{-at} dt = \frac{2!}{a^3} = \frac{2}{a^3}$$

## Application 1: $N$ Identical CSTRs in Series

The RTD for $N$ identical CSTRs, each with a space time of $\tau_i$, is given by:
$$E(t) = \frac{t^{N-1}}{(N-1)! \, \tau_i^N} e^{-t/\tau_i}$$

The raw second moment $\mu_2'$ is defined as:
$$\mu_2' = \int_0^\infty t^2 E(t) dt = \int_0^\infty t^2 \left[ \frac{t^{N-1}}{(N-1)! \, \tau_i^N} e^{-t/\tau_i} \right] dt$$

### Step-by-Step Resolution using the Identity:
1. Pull the constant terms out of the integral:
   $$\mu_2' = \frac{1}{(N-1)! \, \tau_i^N} \int_0^\infty t^{N+1} e^{-t/\tau_i} dt$$
2. Identify the parameters for our Gamma identity: $n = N+1$ and $a = \frac{1}{\tau_i}$. Apply the identity:
   $$\int_0^\infty t^{N+1} e^{-t/\tau_i} dt = \frac{(N+1)!}{\left(\frac{1}{\tau_i}\right)^{N+2}} = (N+1)! \, \tau_i^{N+2}$$
3. Substitute this back into the expression for $\mu_2'$ and simplify the factorials:
   $$\mu_2' = \frac{(N+1)! \, \tau_i^{N+2}}{(N-1)! \, \tau_i^N} = \frac{(N+1)(N)(N-1)!}{(N-1)!} \tau_i^2$$
   $$\mu_2' = N(N+1)\tau_i^2$$

Note: Since $\mu_1 = N\tau_i$, this easily yields the variance: $\sigma^2 = \mu_2' - \mu_1^2 = N(N+1)\tau_i^2 - (N\tau_i)^2 = N\tau_i^2$.

## Application 2: 2 Unequal CSTRs in Series

The RTD for two non-identical CSTRs in series ($\tau_1 \neq \tau_2$) is given by:
$$E(t) = \frac{1}{\tau_1 - \tau_2} \left( e^{-t/\tau_1} - e^{-t/\tau_2} \right)$$

The raw second moment $\mu_2'$ is defined as:
$$\mu_2' = \int_0^\infty t^2 E(t) dt = \frac{1}{\tau_1 - \tau_2} \left[ \int_0^\infty t^2 e^{-t/\tau_1} dt - \int_0^\infty t^2 e^{-t/\tau_2} dt \right]$$

### Step-by-Step Resolution using the Identity:
1. Apply the specific case for $n = 2$ to both terms individually:
   * For the first term ($a = \frac{1}{\tau_1}$): $\int_0^\infty t^2 e^{-t/\tau_1} dt = \frac{2}{\left(\frac{1}{\tau_1}\right)^3} = 2\tau_1^3$
   * For the second term ($a = \frac{1}{\tau_2}$): $\int_0^\infty t^2 e^{-t/\tau_2} dt = \frac{2}{\left(\frac{1}{\tau_2}\right)^3} = 2\tau_2^3$
2. Substitute these solved terms back into the bracket:
   $$\mu_2' = \frac{1}{\tau_1 - \tau_2} \left( 2\tau_1^3 - 2\tau_2^3 \right) = \frac{2}{\tau_1 - \tau_2} \left( \tau_1^3 - \tau_2^3 \right)$$
3. Use the algebraic identity for the difference of cubes ($x^3 - y^3 = (x-y)(x^2 + xy + y^2)$) to simplify:
   $$\mu_2' = \frac{2(\tau_1 - \tau_2)(\tau_1^2 + \tau_1\tau_2 + \tau_2^2)}{\tau_1 - \tau_2}$$
   $$\mu_2' = 2(\tau_1^2 + \tau_1\tau_2 + \tau_2^2)$$

Note: Since $\mu_1 = \tau_1 + \tau_2$, this simplifies straight to the variance: $\sigma^2 = \mu_2' - \mu_1^2 = 2\tau_1^2 + 2\tau_1\tau_2 + 2\tau_2^2 - (\tau_1^2 + 2\tau_1\tau_2 + \tau_2^2) = \tau_1^2 + \tau_2^2$.
